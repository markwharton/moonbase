# @moonbase/6502

The 6502: the documented instructions, run against a machine that gives it `read(address)` and
`write(address, value)`; an assembler for Moonbase's own 6502 code; and a disassembler. The CPU
both machine packages run on.

Part of Moonbase (moonbase.au): Mark Wharton's titles of 1985 to 1995, running again in the browser
on these machines. MIT; see LICENSE. Each file opens with what it is and what it covers.
